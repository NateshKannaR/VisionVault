# Start here

1. Run `npm ci && npm run build && npm run preview`.
2. Open [the local redaction lab](http://127.0.0.1:8080/) and try a sample.
3. Install the Chromium extension from `extension/` using **Load unpacked** in `chrome://extensions`.
4. Open a page with a form or a search box. In the side panel, enter a task, select **Scan active tab**, review the preview, and run the task.

The [project README](README.md) covers full setup, the planner server, and verification. Use the [local portal fixture](isro-panel/README.md) for employee and HR demonstrations.
