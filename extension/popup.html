Fast On-Device executes searches, price filters, form fills, and cart actions on-device in <100ms with zero model lag. Server VLM calls local Ollama or cloud models (~5–15s per step).

OCR is the only stage that reads text baked into images, and the slowest. Measured on the evaluation fixtures: full ≈1.8s per scan, fast ≈0.15s. Redaction runs at every depth.

Risk-based pauses for pay / buy / checkout / submit / delete / sign-up / login / share targets, and for any control with no readable label. Typing is never gated — vault values are substituted on your device.

A consent wall or a login modal swallows every click underneath it, so the agent clears one before acting. It only presses controls whose own text dismisses them — accept, close, not now — never sign-in, subscribe or anything that buys something, and it tells you in the activity log which one it pressed.
