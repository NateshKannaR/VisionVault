How to Install the Extension & Run the Live Demo
Follow these 3 simple steps to load the VisionVault extension in Chrome and execute the autonomous on-device privacy workflow on this portal.
Download Extension (.zip)
STEP 01
1. Download & Extract
Download the extension package archive and unzip it to any local directory on your machine:
visionvault-extension.zip (10 MB)
Or use the existing extension/ directory from the repository.
STEP 02
2. Load into Chrome
  1. Open Chrome and navigate to chrome://extensions
  2. Toggle Developer mode in the top-right corner.
  3. Click Load unpacked button.
  4. Select the unzipped extension directory.
  5. Pin the VisionVault icon to your toolbar.
STEP 03
3. Launch Live Demo
  1. Click the VisionVault icon in your Chrome toolbar to open the Side Panel.
  2. Copy one of the Demo Prompts below.
  3. Paste into the agent chat box and press Enter.
  4. Watch the agent locally redact sensitive PII and auto-fill these portal databases!
