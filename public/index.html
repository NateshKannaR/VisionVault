Stage 1: Screen Capture & Quad-Mapped AXTree Synchronization

CLIENT BOUNDARY (ZERO NETWORK EGRESS) · High-Integrity Local Enclave

Captures a high-fidelity raster framebuffer of the active tab viewport via Chromium's internal IPC buffer (chrome.tabs.captureVisibleTab). Concurrently, the engine traversals the live DOM Accessibility Tree (AXTree), computing exact CSS bounding quads ($Q_{dom} = [x, y, w, h]$) synchronized to viewport coordinates via devicePixelRatio scaling.

// Sub-millisecond raster + AXTree quad synchronization
async function captureSynchronizedFrame(tabId: number): Promise<FrameContext> {
  const [dataUrl, axTree] = await Promise.all([
    chrome.tabs.captureVisibleTab({ format: "jpeg", quality: 90 }),
    chrome.debugger.sendCommand({ tabId }, "Accessibility.getFullAXTree")
  ]);
  const quads = computeAccessibilityQuads(axTree, window.devicePixelRatio);
  return { rasterBuffer: dataUrl, spatialIndex: buildRTreeIndex(quads) };
}
